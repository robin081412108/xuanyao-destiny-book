# Agent Notes

## Project

XuanYao Destiny Book is a premium BaZi and Four Pillars archive experience.

## Guardrails

- Do not commit real secrets.
- Keep user-facing copy calm, premium, and culturally grounded.
- Avoid fear-based claims, cure claims, certainty claims, and master-persona
  imagery.
- Keep pages mobile-friendly.
- Validate with `npm run lint` and `npm run build` before publishing.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
