# XuanYao Destiny Book

Premium BaZi and Four Pillars destiny archive built with Next.js App Router,
TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Scripts

```bash
npm run lint
npm run build
```

## Environment

Copy `.env.example` to `.env.local` for local development. Never commit real
secrets.

## Scope

Task 001 initializes the project shell, route map, shared UI components,
documentation, and first-pass dark gold celestial visual direction.
