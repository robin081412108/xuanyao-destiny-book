# Architecture

## App

Next.js App Router hosts the marketing pages, calculator pages, preview,
checkout, result, recovery, and policies.

## Suggested Modules

- `components`: reusable UI.
- `app`: route segments.
- `lib`: shared content and constants.
- `docs`: product, privacy, payment, and implementation notes.

## Later Services

- Report generation service.
- Payment adapter.
- Snapshot store.
- Recovery and account service.
- Admin content workflow.
